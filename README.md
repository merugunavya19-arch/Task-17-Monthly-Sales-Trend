# Task 17 – Monthly Sales Trend Analysis

## Project Overview

This project analyzes the **Sample Superstore dataset** to summarize sales by month and visualize the sales trend over time. The analysis uses Excel to group sales transactions by year and month and presents the results using a line chart.

## Objective

- Summarize total sales by month.
- Practice date grouping using Excel.
- Analyze sales trends over time.
- Identify increases, decreases, and peak sales periods.
- Create a line chart to visualize monthly sales.

## Dataset

**Dataset:** Sample - Superstore.xlsx

- Rows: 9,994
- Columns: 21
- Data Range: `RawData!A1:U9994`

## Methodology

1. Loaded the Sample Superstore dataset into Excel.
2. Selected the complete dataset range.
3. Created a PivotTable for sales analysis.
4. Added **Order Date** to the Rows section.
5. Added **Sales** to the Values section.
6. Grouped the Order Date by **Years and Months**.
7. Sorted the months chronologically.
8. Calculated the total sales for each month.
9. Created a **Line Chart** to visualize the monthly sales trend.
10. Documented the key observations from the analysis.

## Analysis Performed

The **Order Date** column was used to group the sales transactions by **Year and Month**. The **Sales** column was summarized using the Sum function in the PivotTable to calculate total monthly sales.

A line chart was then created using the monthly sales summary to visualize changes in sales over time. This helps identify high-sales periods, low-sales periods, increases, decreases, and overall sales patterns.

## Key Findings

1. Monthly sales were successfully summarized using Year and Month.
2. The line chart clearly shows the changes in sales over time.
3. The analysis helps identify peak and low sales periods.
4. Monthly sales trends can be used to understand overall business performance.
